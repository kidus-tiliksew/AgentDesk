# Panel keyboard and assistive evidence
Compiled from the shipped DecisionDetailView, AgentDetailView, AgentsView, AnswerControls, and ApproveRejectButtons; only the actions and draft storage are fixtures.
An Accessibility API read shows what an assistive client is given, not what VoiceOver speaks.

## Full keyboard access for this process
Route 1, launch argument -AppleKeyboardUIMode 2: this process's defaults read 2, and NSApp.isFullKeyboardAccessEnabled reads false.
The override did not take effect: AppKit does not read that value from the argument domain.

Real key view loop, Tab and Shift-Tab posted to the transparent window, with NSApp.isFullKeyboardAccessEnabled false:
- approve-reject: Tab Note for the agent (optional); Shift-Tab Note for the agent (optional)
ok approve-reject: Tab reaches the note field
ok approve-reject: Shift-Tab from the last stop walks the same stops in reverse
- single-choice: Tab Note for the agent (optional); Shift-Tab Note for the agent (optional)
ok single-choice: Tab reaches the note field
ok single-choice: Shift-Tab from the last stop walks the same stops in reverse
- multiple-choice: Tab Note for the agent (optional); Shift-Tab Note for the agent (optional)
ok multiple-choice: Tab reaches the note field
ok multiple-choice: Shift-Tab from the last stop walks the same stops in reverse
- free-text: Tab agentdesk-core > Note for the agent (optional); Shift-Tab agentdesk-core > Note for the agent (optional)
ok free-text: Tab reaches the note field
ok free-text: Shift-Tab from the last stop walks the same stops in reverse
- single-choice-or-text: Tab Or type another answer > Note for the agent (optional); Shift-Tab Or type another answer > Note for the agent (optional)
ok single-choice-or-text: Tab reaches the note field
ok single-choice-or-text: Shift-Tab from the last stop walks the same stops in reverse
ok single-choice-or-text: Tab moves from the answer field to the note field

Route 2, NSApp.isFullKeyboardAccessEnabled replaced in this process only: it reads true.
The key view loop did not change: AppKit and SwiftUI decide button focus from a value this method does not supply.
NOT EXERCISED, assigned to the operator's pre-release checks: buttons, links, radio buttons, and checkboxes in the Tab order with the Mac's Keyboard navigation setting on. Neither override reproduces that setting, and the setting was not changed.
