# Testing the installer

`component-installer` §Verification governs this file.

## Automated tests

`pnpm --filter agentdesk test` runs the Vitest project `installer`, and root `pnpm check` runs it with every other package. The tests need Node 22, `sh`, and `curl`; the one test that runs `install.sh` in a pseudo-terminal also needs `python3` and is skipped without it. They need no Bun, no npm, no network, no real harness, and no real harness configuration.

The tests use temporary home directories, a fake `PATH` holding stub `claude`, `codex`, and `cursor-agent` executables that record their arguments (`test/fixtures/fake-harness.mjs`), and an in-process fake gateway that follows `component-gateway` §Sign-in endpoints. The stub `codex app-server` derives each `SessionStart` and `Stop` hook's key, hash, and trust from the sandbox's `hooks.json` and `config.toml`; its hash covers the event and the handler, never the position. The tests prove the installer's side of the protocol, not a live sign-in, not that a harness loads the guidance, and not that a harness runs the resume hooks or resumes a session; only the manual checks below cover that. `test/resume/` covers what the resume hook commands do once they run (`component-resume` §Verification).

## Building

```sh
AGENTDESK_SERVER_ORIGIN=https://agentdesk.example pnpm --filter agentdesk build
AGENTDESK_SERVER_ORIGIN=https://agentdesk.example pnpm --filter agentdesk build:binaries
```

`AGENTDESK_SERVER_ORIGIN` is required and becomes the default server. `build` writes `dist/agentdesk.mjs`, the bundle with the skill and the guidance embedded. `build:binaries` also needs Bun, compiles that bundle, and writes `agentdesk-darwin-arm64`, `agentdesk-darwin-x64`, `agentdesk-linux-x64`, `agentdesk-linux-arm64`, and `SHA256SUMS` to `dist/release/`. The installer is not published to npm (DEC-10).

## Manual check before each release

Run this on a macOS machine and on a Linux host reached over SSH with no display. Use a release candidate's binaries and its deployed gateway. Record the date, the release tag, each host, each harness version, and the result of each step. A step not run stays unverified; the automated tests do not stand in for it.

1. Run `curl -fsSL https://agentdesk.kidus.sh/install | sh`. Confirm the script names the binary for the host, verifies the checksum, installs `~/.local/bin/agentdesk`, prints a `PATH` hint when that directory is not on `PATH`, and then starts the installer with no second command.
2. With Claude Code, Codex, and Cursor installed, confirm the installer lists all three as selected, that no browser opens, and that the prompt reads your answer from the terminal. On macOS this is the check that the compiled binary can read the terminal device `install.sh` gives it; the automated tests run no Bun binary.
3. Enter the printed `XXXX-XXXX` code in the AgentDesk app under Add machine. Confirm the app shows the host name and the three harnesses, then approve. Confirm the installer finishes within 10 seconds of approval, prints no token, and ends by telling you to start a new agent session.
4. Confirm `~/.claude.json`, `${CODEX_HOME:-~/.codex}/config.toml`, and `~/.cursor/mcp.json` hold the `agentdesk` entry; that `~/.claude/settings.json`, `${CODEX_HOME:-~/.codex}/hooks.json`, and `~/.cursor/hooks.json` hold the hook running `~/.local/bin/agentdesk context --harness <id>`; that Codex's `hooks.json` holds a `Stop` group running `~/.local/bin/agentdesk hook stop --harness codex` with `"timeout": 10`; that Cursor's `hooks.json` holds an `afterMCPExecution` entry running `~/.local/bin/agentdesk hook after-mcp --harness cursor` and a `stop` entry running `~/.local/bin/agentdesk hook stop --harness cursor` with `"timeout": 3600` and `"loop_limit": null`; that `~/.claude/settings.json` holds no resume hook; that `config.toml` holds a `[hooks.state."<key>"]` table for the session-start hook and one for the `Stop` hook; that unrelated entries are unchanged; that CLAUDE.md and AGENTS.md are unchanged; and that `~/.config/agentdesk/state.json` has mode 0600 and holds no token.
5. In a new directory with no AgentDesk file, start a new session of each harness. Before sending a message, confirm the agent's context holds the guidance (ask the agent what it knows about AgentDesk). In Codex, confirm `/hooks` lists both AgentDesk hooks as trusted and that `codex exec` runs them. Have the agent call `ask` and confirm each decision reaches the phone.
6. In Claude Code and Codex, run `/compact` (and `/clear`) and confirm the guidance is in the context again afterwards.
7. Run `curl -fsSL https://agentdesk.kidus.sh/install | sh -s -- --only codex`. Confirm only Codex is handled, no code is shown, and the connection keeps working.
8. Run `agentdesk install` again. Confirm no code is shown, every connection keeps working, and the hooks and Codex trust are unchanged.
9. Revoke one connection in the app, then run `agentdesk install` again. Confirm a code is shown only for that harness.
10. Run `agentdesk status`. Confirm each harness shows its connection check, skill version, and session-start hook; that Codex also shows its `Stop` hook and Cursor its `afterMCPExecution` and `stop` hooks; and that each Codex hook shows `trust trusted`.
11. Revoke one connection in the app, run `agentdesk install` again, and decline in the app. Confirm the installer exits with status 1 and prints "Sign-in was declined in the app".
12. Delete the `agentdesk` entry from one harness configuration by hand and run `agentdesk uninstall`. Confirm it exits with status 1, names that connection, and tells you to revoke it in the app under Settings → Connections. Revoke it there, then run `agentdesk uninstall --forget-unrevoked` and confirm it names the forgotten connection. Repeat with `agentdesk install` in place of the first uninstall: confirm it exits with status 1, `agentdesk status` lists the old connection, and `agentdesk forget <connection-id>` removes it after you revoke it in the app.
13. Add a Codex `SessionStart` group after AgentDesk's and a `Stop` group after AgentDesk's in `hooks.json`, trust both in `/hooks`, then run `agentdesk install` and `agentdesk uninstall`. Confirm the app no longer lists the connections; the `agentdesk` entries, skill folders, session-start and resume hooks, both AgentDesk `hooks.state` tables, and `~/.config/agentdesk/resume/` are gone; other entries, hooks, and skills remain; both added Codex hooks are still trusted in `/hooks`; and the state file is deleted.

## Live resume check before each release

`component-resume` §Verification names this check; the automated tests do not stand in for it. Run it after step 5 above, with the release candidate installed by `install.sh`, in four sessions: Claude Code, Codex under the default `workspace-write` sandbox, Codex in a thread hosted by T3 Code, and the Cursor CLI (`cursor-agent`). Use a repository with no AgentDesk file.

For each session:

1. Ask the agent to ask you a confirm question through AgentDesk and then end its turn. Confirm the question appears in chat and on the phone, and that the turn ends without the agent waiting on the answer.
2. Answer the question in the AgentDesk app on the phone. Record the time of the answer.
3. Confirm a new agent turn starts within 60 seconds of the answer, with no message typed in the session. Record the time the turn starts. Confirm the agent's first message states the answer and that it came from the phone (`req-installation-and-agent-guidance` AC-12.8).
4. Have the agent ask a second question, then answer it in the chat instead of on the phone. Confirm the agent relays the answer through AgentDesk and that no further turn starts after the session goes idle; wait at least 60 seconds.

Record, for each session: the date; the release tag; the host; the harness version (`claude --version`, `codex --version`, the T3 Code version, `cursor-agent --version`); for Codex, the sandbox mode; the answer time and the resumed turn's start time from step 3, and their difference; the result of each step; and any step not run. A step not run, or a session not checked, is recorded as unverified, never as passed.
